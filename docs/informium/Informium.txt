Informium is a fully featured advanced news script intended for use within web site.  Informium was programmed in PHP 4+ and uses a MySQL backend for its database.  Informium features the ability to add, edit or delete users of differing access levels, adding and editing of posts as well as comments.  Informium simplifies the user experience a very refined and easy to use interface.  Behind the scenes, Informium features a well thought out and consistent structure and extensive code documentation.  Informium's components are nicely separated in to appropriate files and easy to edit and understand.
